# V2 平衡记录

数值的初值来自用户GDD；当前运行源是src/v2/data.ts和world.ts。普通预算2800/600仿真秒，英雄招募也花费预算，没有免费全军复制。圣晶HP5600，其他设施不改变时间。

克制通过真实属性实现：史莱姆42HP面对88伤害重炮范围射击会成批损失；巨人550HP和×4攻墙承担破口职责；飞龙越墙但防空每轮72伤害；狼/狼骑选择射手且受骑士增伤；树人治疗不叠加；专精与手动治疗/祝福能保存精锐和提高接敌窗口的输出。

三种预设由同一账本购买。固定种子9场见V2_BALANCE_RESULTS，保留败局；普通巨人组合与空袭组合均有获胜样本，纯史莱姆正门未触及核心即失败。浏览器还用战利品补充基础兵/精锐并在受伤时治疗、接敌时祝福，实际完整通关。

不要从3个种子估计总体胜率。脚本技能时间与购买选择并非最佳策略，未花完而可改购的余额仍能延续战斗，这符合真实力竭定义。后续应由独立玩家测试至少更多地图入场时机、无飞行统帅组合、四统帅高费用阵容、分线与预备队策略，记录战损/进度/时间，而非把每个策略调成同样稳赢。
