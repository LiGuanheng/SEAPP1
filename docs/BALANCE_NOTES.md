# 数值与调参记录（Balance Notes）

> 所有数值集中在 `src/config/balance.ts` 与 `src/config/mapData.ts`。
> 本文记录**实际跑过的模拟**与改动原因，不宣称"已完美平衡"。

## 初始草案（来自 GDD）

| 项目 | 值 |
|---|---|
| 开局 | 60 食尸鬼 / 50 尸骸 / 8 精华 / 王座 I / 尸巢 I |
| 尸巢 | I/II/III = 12/22/35 食尸鬼/天 |
| 外墙 / 城门 / 内墙 | 1400 / 2600 / 1800 HP |
| 机枪塔 / 重炮塔 | 800 HP / 28 DPS；950 HP / 60 每 3.5s |
| 灯塔 | 6000 HP |

## 第 1 次实测（Vitest headless 模拟，`tests/battle.balance.test.ts`）

- 60 食尸鬼（第 1 天）：0 生存，仅击杀 7 名守军，但**摧毁了 6 段城墙**（含一段内墙）。
  → 墙体过脆，一天的攻势就能在城防上开出过多缺口，失去"逐日积累"的节奏感。
- 220 食尸鬼 + 24 重装 + 1 巨汉（终局）：121 秒胜利。
  → 终局强度合适。

## 第 2 次调整

| 改动 | 原值 → 新值 | 原因 |
|---|---|---|
| 外墙 | 1400 → 3200 | 让"重装破墙"成为需要投资的选择，而不是附带效果 |
| 外城门 | 2600 → 5200 | 正门应是硬目标 |
| 内墙 | 1800 → 4200 | 内城是最后防线 |
| 内城门 | 2200 → 5200 | 同上 |
| 灯塔 | 6000 → 9000 → 12000 | 提高终局目标血量，避免"摸到就赢" |
| 开局尸骸 | 50 → 80 | 让玩家第 1 天能在"建尸巢"与"升尸巢"之间做真实取舍 |
| 初始守军 | 10 → 14 | 增强前期压力 |

结果：
- 第 1 天：仍会打开缺口，但**打不到灯塔**（12000 满血）。
- 第 5 天规模（150 食尸鬼 + 8 重装，王座 II）：打通 **6 段墙**（含外城门与内墙），但全军止步内墙，**灯塔 12000/12000 完全未受损**，时间耗尽失败。
  → 比"差一点"更严峻：中期兵力根本摸不到灯塔，只有把兵力滚到终局规模才有胜算。这一点已列入待调项。
- 终局（222 食尸鬼 + 24 重装 + 巨汉）：119 秒胜利。

## 第 3 次调整（内城强化）

- 新增 4 座塔（内城两翼机枪、门前重炮、灯塔旁圣光），机枪 28→34 DPS，重炮 60→80 每发。
  → 目的：让"正面硬冲"付出代价，迫使玩家用重装破墙、疾行者切后排、或先拆能源站拖时间。

## 第 4 次调整（精华经济可行性）

**问题**：V1 初始只有 8 精华，全地图三处据点合计仅 +8，而王座 II 需要 12、祭坛 12、巨汉 25。
结果是**"唤醒巨汉 / 提前发动万骸归一"两条路线在数学上不可达**——这是真正的设计缺陷，不只是"偏难"。

**修正**：

| 来源 | 改动 |
|---|---|
| 开局精华 | 8 → 12 |
| 击杀掉落 | 每 4 名人类守军 +1 精华 |
| 摧毁设施 | 每座设施/炮塔 +3 精华 |
| 据点奖励 | 西/东 3→4，城前 2→3 |

**验证**（`tests/campaign.test.ts`「精华经济可行性」）：每场 24 击杀 + 2 座设施 → 每场至少 +12 精华；
6 场后 ≥84，足以覆盖祭坛（12）+ 王座 II（12）+ 巨汉（25）。测试通过。

## 已知问题（待真实试玩校准）

1. 单位在城墙前会堆叠成两团，实际有效攻击面比理论小，导致破墙时间偏长。
2. 疾行者/蛛行者的"优先目标"逻辑还没有被数值验证过（缺少对炮塔的针对性测试）。
3. 人类 AI 的建塔预算尚未在长局中验证，可能在后期积累过多塔。
4. 简单/困难难度只是参数缩放，未分别调校。

> 以上均在 `docs/TEST_REPORT.md` 的"已知缺陷"中同步记录。
