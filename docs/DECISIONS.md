# V3 设计决策

- 核心早死由空间、防线、视线与防空覆盖修复；圣晶保持5600HP，不用巨额生命或强制全清规避问题。
- 地图扩大为4000×3600的四向围城，三环四门构成外围/外城/内城/核心四层。各门错位、侧墙强弱及资源不同，保持穿插与斩首可能。
- 外城/内城/核心固定塔有防区边界；攻击另受类型/射程/实际遮挡限制。防空范围齐射仅伤飞行单位，飞行普攻对建筑55%，空袭仍有胜例。
- 人类预备队在开局就有实体与有限队伍，按压力调动并实际移动。停止旧计时刷兵逻辑，不接模型API。
- 新通用兵不占统帅名额：掠夺者负责附近经济目标及自卫，精灵用低生命/前摇/射程/遮挡换取范围清兵能力。
- 通用法术与三专精F并存，快捷键Z/X/C/V避开Q/W/E/R/F。目标需活体友军提供近距视野，陨星对核心仅45。
- 长按用渲染循环提供单调时间，避免独立定时器在失焦或新战役继续扣库存。默认3批、更多批数、保留点放模式和集结点按钮同时服务快下兵与精细部署。
- 三难度预算/倒计时重新校准，不让扩大地图仅靠走路消耗旧时限；不加拆塔延时机制。
- 城墙按破坏阶段缓存，保留动态旗帜/HP及排序，缩远不绘制所有满血条；画面可读性与性能一起验收。
- 原需求、旧课设、首轮失败和真实测试数据保留。长战役的模拟快进与人类实时试玩严格区分，样本胜利不冒充总体胜率。
