# 玩家手册 V3.2

推荐电脑浏览器全屏，至少1280×720。[在线游戏](https://liguanheng.github.io/SEAPP1/)。新手可选简单、进化、群山破城预设，从西境尝试破壁。

## 更快下兵

1. 出征后可点右上角南/西/东/北切换方向，同时设置对应初始集结点。
2. 部署数量默认1批，可改1、3、5、10批或全部库存。
3. 选兵种卡，再点绿色合法区域；选择保持，可以反复点地图。默认长按也只投当前批数；勾选“长按连下”才会持续投放，松开即停；Esc或右键取消模式。
4. 点“设置集结点”，在合法区域确认。随后点任意卡片下方“出兵N”即可一键投到该点；明确选择部署“全部库存”才投该兵种全部；Shift不改变数量。“一键全军”投入所有库存与待部署英雄。
5. 原生拖放仍可用。英雄只能部署一次。超过300活动友军的军队排队，不会丢失；买兵消耗魔晶，部署只消耗库存。

只有勾选“长按连下”才会在600ms后开始，约每500ms投一次当前设置批数；失焦、暂停、库存用尽或战役结束会停止。暂停时仍可单次购买、规划部署，但不会连续投放。

## 选兵与行进轨迹

**下兵后原地待命。** 底栏“库存部署”负责出兵，“战场选兵”点击卡片选择全场同类，Shift追加。也可左键点选、框选或双击同类。按住右键在地图画出路线，Shift+右键追加路点；沿路优先级可改为资源、城防、守军、弓法、重甲。路线表达大致进攻方向，部队会主动清理附近所有可攻击建筑（包括城区建筑）和守军；优先级只影响先后。受到守军或塔攻击时，自身和附近友军反击，交战后继续原路线/集火命令。清完终点周围威胁才停留。待命也会受袭反击，之后归位；不会追到整张地图另一边。单击敌人右键集火，击破后待命；S停止推进，保持自卫，Tab切换底栏。路线用金色箭头显示，拖动时有青色预览。

## 四面城市与经济

西境有薄弱墙和矿场；南面主门重炮密集；东面防空/弓手强；北面法师、林地与补给并存。可以集中一路，也可分兵掠夺与佯攻。镜头四周均可进入，中键拖动、滚轮缩放、小地图定位，全景查看整张地图。

外城、内城、核心各有真实围墙及不同位置的门。完整墙体挡住地面通行和攻击视线，破坏后军队自动利用缺口。巨王Q需指向附近可见墙段；巨人普攻对墙×4。飞龙能越墙，但扎堆会受到防空齐射，对建筑普攻仅55%伤害。

掠夺者优先附近资源，对资源×3伤害，击毁额外+90；不是忽略近处危险的寻财机器人。精灵法师可清理密集守军，脆弱且咏唱需要保护。资源与据点分布在四面，资源奖励为运输车360、军需450、矿场500、仓库600；收益只结算一次。

前线需打通地面、排除敌军争夺，地面部队站稳8秒，奖励200并允许就地部署。战中“＋价格”按钮买进库存，再从前线合法集结点继续出兵。

## 指挥与法术

| 操作 | 按键 |
|---|---|
| 框选/追加 | 左键拖框 / Shift追加 |
| 路线/追加/集火 | 右键拖画 / Shift+右键追加 / 单击目标 |
| 待命/底栏模式 | S / Tab |
| 全选/编队 | A；Ctrl+1/2/3存组，1/2/3调用 |
| 统帅主动技能 | 按招募顺序Q/W/E/R |
| 专精魔王技能 | F |
| 狂暴/治疗/守护/陨星 | Z / X / C / V |
| 暂停/倍速 | 空格；顶部1×/2× |
| 镜头 | 中键拖动、滚轮、小地图、方向按钮、方向键、Home全景 |
| 取消 | Esc；部署/施法模式中右键也可取消 |

通用魔法有100法力上限，每秒恢复1.8；点击技能后点地图，或拖图标到地图。需360距离内活体友军提供无遮挡视野。先治疗受伤精锐、守护保护缺口、狂暴助突破；陨星55法力/60秒冷却且有预警，不能远程偷掉圣晶。技能冷却、魔力不足和范围预览都在下方显示。

“全军自动进攻”明确命令当前军队与已排队军队自动推进，保留手动集火；后来新部署仍待命。普通守军会归位，内城预备队及安静侧翼会沿真实道路增援。塔射程和邻区覆盖扩大，悬停可看射程。

推荐先让掠夺者沿城外分路夺取物资，保护精灵/射手，购买巨人等攻城援军。拆外城火力并占前线，清理内城火力后再决战。中央有日轮守护骑士与精锐驻军：震荡带短暂定身和护盾，蛛后定身可打断其出手机会，护盾期间及时治疗/守护。无需全清资源；直接全军硬冲在困难样本中失败。

## 胜败与重开

圣晶5600HP，是唯一胜利目标，不必清掉所有建筑。简单18分钟、普通15分钟、困难15分钟；净化充能只是倒计时视觉，拆建筑不加时。超时，或所有军队/库存/队列/英雄与可购买作战力量均耗尽，才失败。魔王阵亡本身不直接判败。

结算支持原阵容重试、重新配兵和主菜单。既有实测策略见v3/REPORT；它们是样本，不保证所有种子与操作时机都必胜。
