# 玩家手册（User Manual）

**《丧尸围城：亡骸君主》 v1.0**
线上游玩：**https://liguanheng.github.io/SEAPP1/**
（桌面 Chrome / Edge，建议 ≥1366×768；无需账号、无需下载）

---

## 1. 你将扮演谁

亡骸君主·阿兹拉克。你从古墓中苏醒，统领尸潮进攻人类最后的城市「曙光城」。城心的**中央灯塔**正在充能——一旦充满 100%，所有亡灵都会被净化。

**你的目标**：在充能完成前摧毁灯塔，或者在最后关头发动一次性终局「万骸归一」，把整个王国烧成最后一支大军。

---

## 2. 一局的节奏

```
主菜单 → 开场（可跳过） → 议事厅（建设/改造/配兵）
      → 攻城（实时，4 分钟） → 战报 → 人类发展 → 灯塔充能
      → 次日议事厅 …… → 胜利 / 失败
```

- **每天只能打一次攻城**，可以随时撤退。
- **战果跨天保留**：墙上的缺口、被拆掉的炮塔、占领的据点都不会复原。
- 建设与升级**次日才生效**；能源站被摧毁**当天**就降低充能。

## 3. 议事厅（经营）

| 区域 | 作用 |
|---|---|
| 顶部 | 天数 / 尸骸 / 精华 / 统御上限 / 守军 / 灯塔充能 + 预计充满日 |
| 左侧 | 王座升级、六个建造点（腹地 3 个 + 三处前线各 1 个）、变异改造、尸骸招募 |
| 中间 | 战略地图，可点击幽绿圆环选择建造点、查看城墙缺口与据点 |
| 右侧 | 人类设施血量、防御塔数量、城墙缺口、前线归属 |
| 底部 | 出征兵力、**发起进攻**、**万骸归一**、保存并返回 |

### 建筑

| 建筑 | 作用 | 造价 |
|---|---|---|
| 尸巢 I / II / III | 每天 +12 / +22 / +35 食尸鬼 | 30 尸骸 / 45 尸骸 / 65 尸骸+10 精华 |
| 变异池 | 改造精锐（2 级解锁蛛行者） | 45 尸骸+8 精华；升级 70+15 |
| 黑暗祭坛 | 唤醒斧头巨汉 | 65 尸骸+12 精华 |
| 亡骸王座 II / III | 统御上限 180→300→450 | 70+12 / 130+25 |

### 精锐改造（需变异池）

| 目标 | 消耗 |
|---|---|
| 疾行者 | 2 食尸鬼 + 2 精华 |
| 重装感染者 | 4 食尸鬼 + 4 精华 |
| 蛛行者（需 2 级变异池） | 2 食尸鬼 + 3 精华 |
| 斧头巨汉 | 25 精华 + 祭坛；重伤后休整 1 天 |

## 4. 攻城（实时战斗）

### 操作

| 按键 | 功能 |
|---|---|
| `1`–`5` | 选择兵种卡（食尸鬼 / 疾行者 / 重装 / 蛛行者 / 巨汉） |
| 左键 | 部署模式下：在幽绿区域投放一批；否则点选单位 |
| 左键拖拽 | 框选部队 |
| 右键 | 移动 / 集火（指向敌人或建筑）；部署模式下取消 |
| `Esc` | 取消部署模式 / 取消选择 |
| `WASD` | 平移镜头 |
| 滚轮 | 缩放镜头 |
| `空格` | 镜头回到主军 |
| `P` | 暂停 / 继续 |
| `F` | 全军冲锋（把剩余预备队全部投入并推进） |
| `1×` / `2×` | 战斗速度 |

### 兵种差异（不是换皮）

| 单位 | 特点 | 默认批次 |
|---|---|---|
| 食尸鬼 | 便宜、成群、能缓慢拆墙 | 30 |
| 疾行者 | 高速，优先撕远程守军与炮塔 | 12 |
| 重装感染者 | 慢、肉，对墙门 2.5 倍伤害 | 4 |
| 蛛行者 | 侧翼猎手，优先攀向炮塔 | 8 |
| 斧头巨汉 | 2500 HP / 90 DPS，对建筑 3.2 倍 | 1 |

### 三条路线

1. **正门**：沿主路推进 → 破外城门 → 医疗中心 → 内城门 → 灯塔。
2. **西线**：夺西侧哨站 → 破西墙 → 西军营 → 能源站甲 → 内城西墙。
3. **东线**：夺东侧补给站 → 破东墙 → 东军营 → 能源站乙 → 内城东墙。

> 拆掉能源站可以把日终充能从 16% 压到 13% / 10%，为多打几天争取时间。

### 占领前线

清光据点附近守军，并让至少 1 个亡灵在圈内待满 **8 秒**即可占领。**次日**才能在更靠前的位置投放部队。

## 5. 胜负条件

| 结果 | 条件 |
|---|---|
| 胜利 | 灯塔 HP 归零（普通攻城或终局都算） |
| 失败 | 日终充能达到 100% |
| 失败 | 超过最大天数（普通 10 天）仍未破城 |
| 失败 | 终局总攻超时 |

### 万骸归一（不可逆）

- 解锁条件：王座 II，或进入「最后机会」（当日充能会满 / 已是最后一天）。
- 效果：所有建筑崩塌、资源清零，库存 + 尸巢献祭 + 尸骸兑换 + 精华重塑 → 一次性总兵力；君主化身登场；解除统御限制。
- **只能发动一次，发动后没有下一天。**

## 6. 存档

- 进入议事厅、战报确认、终局确认时**自动保存**到浏览器 localStorage。
- 主菜单「继续战役」读取。
- **战斗中刷新会回到战前的议事厅**（战场进度不保存，但战役不会丢）。
- 换浏览器/清缓存会丢失存档（无后端）。

## 7. 设置

- **音效开关**：程序化合成音效（破墙、炮击、部署、胜负），可静音。
- **画质**：低画质降低同屏活动单位上限（260→180）并减少粒子。

## 8. 常见问题

**Q：为什么点了兵种卡却没出兵？**
A：顶部会提示原因：库存不足 / 统御不足 / 不在合法部署区 / 位置被占据。请注意底部卡片的库存数字与左上角「统御」。

**Q：为什么打不动灯塔？**
A：灯塔在内城，需要先破外城 → 内城。重装与巨汉对建筑伤害更高。

**Q：为什么我的兵一会儿就死光了？**
A：塔的火力很猛。先用食尸鬼吸引火力、用疾行者切炮塔、用重装破墙，不要一次性平推。

**Q：一天能打几次？**
A：一次。撤退也算用掉当天。

**Q：为什么建设没有立刻生效？**
A：规则如此——当日投入，次日生效。

**Q：没有声音？**
A：浏览器要求先点击页面才允许播放音频；点击「开始新战役」后音效才会启用。也可以在设置里确认没有被静音。
