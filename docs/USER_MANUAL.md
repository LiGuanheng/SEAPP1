# 玩家手册

## 开始总攻

主菜单→难度→魔王专精→招募1–4位统帅→购买军团→出征。初次可选简单与“群山破城”推荐阵容。推荐阵容会替换当前军团与统帅，确认右侧清单再开战。普通预算2800包含统帅费用，购买后未花完的魔晶保留到战中。

中央日轮圣晶是唯一胜利目标。击毁墙、军营、据点不会延长倒计时；不必清光守军或先杀骑士长。

## 购买与部署

兵种卡下方购买按钮用于付费入库。底栏选择买1/3/尽可能多批，部署1/3/全部库存。点击兵种卡后点地图，或直接把卡拖到绿色合法区；非法位置不扣库存。底栏过长可使用鼠标滚轮横向浏览。

三处初始召唤区位于城外西/中/东。“全部部署”需要再点一次合法位置，真实库存与英雄将排队出场。300只友军上限之外的队伍继续等待，不会消失。英雄同样要拖出场，死亡不能再招募。

## 快捷键

| 操作 | 方法 |
|---|---|
| 框选/追加 | 左键拖框 / Shift |
| 移动/集火 | 右键地面 / 敌人或建筑 |
| 全选 | A |
| 保存/回选编队 | Ctrl+1/2/3 / 1/2/3 |
| 魔王技能 | F后左键选目标 |
| 统帅技能 | 按选择顺序Q/W/E/R后左键 |
| 取消当前操作 | Esc |
| 暂停 | 空格或按钮 |
| 镜头 | 中键拖动、滚轮缩放、方向键、小地图 |
| 城池全景 | Home或“全景” |

移动到位后会驻留；“全军冲锋”恢复自动推进并保留你的指定集火。打开战场手册会暂停，关闭后恢复原状态。

## 战术提示

- 正门最短但有密集重炮与骑士。纯史莱姆容易被范围炮火成批消灭。
- 让巨王与岩甲巨人拆薄弱侧墙，近战/远程协同推进，狼类选择射手侧翼。
- 龙可越墙，但先用地面部队拆防空更稳妥。龙息是以龙为起点的扇形。
- 女王治疗留给受伤的重装和英雄；进化祝福在部队真正接敌时使用，提前空放会浪费窗口。
- 占领据点需要地面打通、清除守军并站稳8秒，争夺时不能增援。占领+200，可从前线投放新买的兵。
- 勿忘花战利品：后期少量射手、巨人或基础兵也可能完成最后一击。

超时，或场上/队列/库存/英雄均耗尽且资金买不起任何已解锁兵，才会失败。魔王死亡不立即失败。战报可以原阵容重试或返回配兵；刷新页面回主菜单，没有中途战斗存档。
