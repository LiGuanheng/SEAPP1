| 层级 | 工具 / 证据 | 口径 |
|---|---|---|

| 逻辑 | `evidence/unit-results.json` | 最终48项，含经济/队列/技能/碰撞/胜败/固定步长 |

| 预览子路径JS返回HTML | build和preview都使用/SEAPP1；生产版本重新跑浏览器 |
| 超时浮点残差使界面显示1秒 | 同胜败判断阈值归零；600秒固定步长测试与真实失败结算 |
| 测试把浮点地图点要求严格等于1360 | 使用1px容差；前线购买暂停观察真实队列，仍检查一次付费与真实库存 |
| 早期脚本过早结束或浪费技能 | 等待真实终局，治疗受伤精锐、祝福接敌军团、用剩余预算补基础兵；保留真实胜负 |
| 旧浏览器测试依赖审计问题 | 升级Puppeteer并补Node类型；干净安装、原生拖拽再验证，当前审计0漏洞 |

## 限制

性能来自单台Windows无头Chrome，JSON给出逻辑核数与设备报告内存；JS heap不包含Canvas/图像/GPU或整个浏览器进程。固定300采样与实际交战的单位范围分开记录，不能把有战损的采样伪称始终300。

没有独立人类盲测、低端设备/移动端覆盖、完整实时视频或统计学平衡试验。美术已实际迭代并检查，但“达到商业独立游戏水准”不是自动测试能证明的结论。剩余问题与最终线上状态见V2_REPORT。
