# M5 测试发现与修复

首次实际Chrome压力场景（2026-10-24 06:17，UTC+8）测得10秒中友军数量从300降至90，不能作为“300单位稳定同屏”通过证据。检查发现移动指令抵达目的地后立即被自动进攻覆盖，部队自行离开编队并接敌。

修复：移动指令保持驻留，只有玩家发出新命令/全军冲锋才解除；附近敌人在武器范围内仍可自动攻击。增加回归测试验证抵达后4秒不会自行离位。随后重新以合法购买和部署的军团、真实编队命令进行压力测试，整个10秒保持300单位，151单位继续排队。最终数据见 `../V2_PERFORMANCE_RESULTS.json`。

重开测试也验证旧仿真不再推进、旧键盘监听器不再响应、当前只有一个战场和一个小地图Canvas。这里不把界面帧率外推到其他硬件或浏览器。
