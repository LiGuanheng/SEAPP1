# 《异界围城：魔物之王》需求规格说明书

版本：V2.0｜日期：2026-10-24（北京时间）｜用途：软件工程课程项目

## 1. 范围与变更基线

V2是对V1《丧尸围城：亡骸君主》的真实需求变更与全面重制。历史基线为 `d4aa44d`，V1文档与截图在 `archive/v1/`，全部Git提交保留。V2不含天数推进、尸巢、建造经营、科技树、跨日战役、双货币、联网对战或大模型运行时API。

原始需求以 `v2-source/GDD.md`、`ACCEPTANCE.md` 与 `EXECUTION.md` 为依据。目标是单场实时奇幻攻城，唯一胜利目标为中央日轮圣晶。

## 2. 用户与环境

- 单人PC浏览器玩家，键盘鼠标操作；不要求账号、服务器、GPU计算或模型API。
- 最低界面尺寸1280×720，主要展示尺寸1920×1080；移动端不在承诺范围。
- 静态HTML/CSS/JavaScript，可发布GitHub Pages；开发构建需要Node.js 22+、npm。
- 正式资源随站点加载，无字体CDN或外部游戏服务依赖。仅静音偏好使用独立V2本地存储键。

## 3. 主用例

玩家从主菜单进入，依次选难度、专精、1–4位统帅、购买军团。预算同时覆盖招募与兵种批次；未使用魔晶进入战场。开始总攻后，玩家从三处城外区域部署库存，指挥部队和施放技能，破坏城墙、占领两侧前线、购买并部署援军，最终摧毁中央圣晶，或因超时/真实力竭失败。结算后可原阵容重试、重新配兵、返回菜单。

## 4. 功能需求

| ID | 需求与边界 |

| FR-01 | 菜单、帮助、难度、专精、统帅、整备流程完整，可返回 |
| FR-02 | 召唤/进化/元素三专精互斥；魔王免费、只能部署一次，死亡不直接失败 |

| FR-13 | 有限驻军、弓手/骑士/法师/圣殿骑士/骑士长、四类炮塔与最多三波预备队；传统规则AI |
| FR-14 | 简单3400/720s、普通2800/600s、困难2500/480s；防御密度随难度变化 |
| FR-15 | 圣晶HP归零立即胜；超时或所有可用军力与购买/召唤手段耗尽才败；同更新胜利优先 |

| FR-18 | 原创奇幻菜单、立绘、战斗精灵和建筑；可跳过巡城，破墙/龙息/炮火/圣晶终局事件演出 |
| FR-19 | 干净安装、类型/格式检查、测试、生产构建、真实浏览器及Pages子路径可用 |

## 6. 非功能需求与验收边界

| ID | 验收口径 |
|---|---|
| NFR-01 | 200–300友军时可操作；记录实际浏览器采样环境、FPS和可获得内存，目标≥30FPS，不向其他机器外推 |
| NFR-02 | 两种PC尺寸可操作，缩放/坐标转换正确；长兵种栏支持横向滚动 |
| NFR-03 | 固定60Hz步长、确定性随机、ID唯一、资金非负、奖励一次、输入模式互斥 |
| NFR-04 | 无运行时模型API、无密钥和商业游戏资产；素材来源可追溯 |
| NFR-05 | 不重写或伪造Git历史，阶段正常commit/push，清理范围只在仓库内 |
| NFR-06 | 至少两轮真实全景/近景检查；十兵种与六统帅可辨，防线可交互。商业美术完成度与乐趣仍需用户主观试玩评价 |

验收案例TC-01～TC-20见 `TRACEABILITY.md`。实时模拟与浏览器证据分开报告；不会把编译成功当作整局通过。
