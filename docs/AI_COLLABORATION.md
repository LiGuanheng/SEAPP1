# V3 AI协作与真实性说明

本轮依据用户提供的重大改造文本（v3/REQUEST.md）及“下兵不要全拖动、增加一键批量与长按连投”的追加要求实施。AI执行源码审查、TypeScript/Canvas/DOM开发、原创美术提示词和资源整合、自动化测试、固定种子仿真、课程文档与正常Git提交/推送。

没有新增分代理、编造人工测试、修改历史提交日期或强推。原始开发历史与V1/V2课程资料保存。游戏运行时只使用本地规则AI，不调用大模型API。

新增图集通过内置image_gen生成：art-source/v3-units.png和v3-city.png，完整提示词见v3/ART_PROMPTS.md。它们是开发素材，不是游戏运行截图。真实画面由Chrome在本项目实际运行时截取，位于screenshots/v3；没有用生成图冒充截图。

模型测试与浏览器测试分开；浏览器通过真实菜单/配兵/购买/部署/技能交互完成战役。为了加快长战斗，使用同一固定60Hz模型的advance接口，没有覆盖生命、资金或胜利状态。局部单元测试会隔离守军或搭建测试对象，不将它们当成完整通关样本。

原始JSON、阶段提交、失败案例和修复记录可审计。没有第三方独立真人盲测、统计胜率或所有硬件流畅度保证；已知动画与平台边界在最终报告中明确列出。

V3.1继续依据用户的选兵、轨迹、加固城防与外城掠夺/内城决战要求实际开发。没有额外生成美术；沿用合法原创图集，增加守护骑士尺寸/护盾/震荡及路线预览。当前测试与截图独立位于v3.1和screenshots/v3.1，不混用旧3.0结论。

V3.2根据用户反馈继续实际修复自主进攻、受袭反击和按批出兵；没有新增分代理或商业美术。模型测试和实际浏览器数据独立保存v3.2，普通点放/原生拖放/Shift/连投的库存差值来自真实UI操作。路线性能首次失败保留，修正共享寻路后重新验证，不将旧版本通过数据混入本次。
