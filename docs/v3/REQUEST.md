# 《异界围城：魔物之王》V2 下一轮重大改造任务

请在当前 SEAPP1 游戏项目中，进行一轮以**帝国城池纵深防御、四面进攻、战场经济、魔王法术和战术平衡**为核心的重大改造。

现有仓库：https://github.com/LiGuanheng/SEAPP1

这次不是微调参数。我已经试玩了当前版本，发现核心战斗体验存在明显问题：

1. 简单难度可以很快直接摧毁中央圣晶。
2. 困难难度下，还没有真正攻入城池后部，中央圣晶就已经被摧毁。
3. 城池虽然有大量建筑，但很多后方建筑、守军和防御设施根本没有机会参与战斗。
4. 当前防线缺少清晰的外围、外城、内城和中央核心层次。
5. 玩家进攻方向与部署策略的价值不够明显。

请首先调查真实源码、地图配置、攻击范围、单位寻路、敌军 AI、胜利判定和难度参数，找到这些现象的实际原因。

允许对地图、战斗系统、AI、单位行为、经济和 UI 进行大规模重构。不要只通过增加中央圣晶生命值来掩盖问题。

## 一、重新设计圣曜城：四层纵深防御体系

将圣曜城重新设计成一座宏伟、具有真实军事纵深的奇幻帝国要塞。

必须包含四个防御层次。

### 第一层：城市外围

包含城外道路、废墟、森林、军事前哨、补给营地和魔晶资源点。

玩家从地图东、西、南、北四个方向的合法集结区组织进攻。

外围可以放置少量帝国巡逻队、轻型哨塔和资源据点。

外围不应该被内城远程炮塔直接覆盖。

玩家可以选择集中一路强攻，也可以从多个方向同时进攻。

### 第二层：帝国外城

这是第一道真正坚固的防线。

包含：

- 大型外城墙与多座城门
- 箭塔、轻型魔导炮
- 帝国步兵、弓箭手和少量骑士
- 资源仓库、兵营和外围军事设施
- 可以被破坏的墙段与侧翼突破口

外城需要足够广阔，容纳数百只魔物展开进攻。

玩家可以攻击城门，也可以让巨人打破薄弱城墙，或利用其他兵种从侧面突破。

### 第三层：帝国内城

内城拥有更坚固的城墙和更精锐的部队。

包含：

- 帝国骑士团
- 精锐步兵
- 帝国法师
- 重型魔导炮
- 圣光防御设施
- 内城预备队营地

内城部队可以出城支援外围或外城。

例如南面遭遇大量魔物进攻，人类指挥系统可以派出一部分内城预备队，沿实际道路前往南面增援。

但不能凭空刷新或瞬间传送。

**特别注意：内城建筑和防御塔不能直接攻击远在外围的魔物。**

固定防御建筑应该受到真实射程、遮挡关系和防区限制。

外城主要由外城设施防御，内城主要由内城设施防御。

内城机动部队可以支援外城，但必须真实移动。

### 第四层：中央核心

城市最中央是唯一胜利目标：

**日轮圣晶。**

中央核心周围布置少量高威胁精锐防御，例如圣剑骑士长、圣殿守军和核心圣光塔。

玩家突破外围、外城及内城后，才能比较稳定地接近中央圣晶。

但不要强制玩家必须消灭全部守军或摧毁所有建筑。

优秀玩家仍然可以采用快速突破、侧翼突袭或精锐斩首战术直接攻击中央圣晶。

只是这条路线必须真正承担突破纵深防线的成本与风险，不能开局站在外围就轻易打到核心。

## 二、实现真正的四面八方进攻

请彻底检查当前地图和镜头系统，保证整座城市的四面都可以实际进入、部署和指挥。

要求：

1. 地图四周都有明确且合法的初始出兵区域。
2. 北、南、东、西至少各存在一条可行的地面攻城路线。
3. 不同方向拥有不同的城墙结构和防御组合。
4. 各个方向之间通过城市道路连通，允许军队迂回。
5. 玩家可以选择集中一路、多路佯攻或四面围城。
6. 部队不能穿越完整的不可通行城墙，也不能无视障碍直接攻击内部建筑。
7. 破墙之后，寻路系统能够及时更新，魔物可以自然涌入缺口。
8. 玩家能够方便地查看整张地图、拖动镜头、缩放和切换进攻方向。

不要只在原地图外围增加几圈装饰性建筑。

四个方向的防御和实际可通行路径必须真正不同，能够影响战术结果。

## 三、重新设计人类防御 AI

不需要接入大模型 API，使用传统游戏规则 AI 即可。

请建立清晰的分区防御机制。

### 固定建筑

- 只能攻击真实射程内、符合目标类型的敌人。
- 不允许隔着完整墙体或大型建筑无条件攻击。
- 外城防御塔优先负责外城区域。
- 内城防御塔优先负责内城区域。
- 核心防御塔负责中央圣晶附近。
- 不允许内城炮塔跨越整个地图直接轰炸外围军队。

### 普通守军

守卫各自的城墙、道路和设施。

在合理的警戒范围内主动迎敌。

敌人撤退后，可以回到防御位置，不要全城所有守军追逐一只史莱姆。

### 预备队

人类可以从内城派出有限的预备队支援外城。

例如：

- 南门正在遭受猛烈进攻，人类派遣一支骑士队支援。
- 西侧受到少量佯攻，不应立刻调动所有精锐。
- 多处同时遭到攻击时，人类需要在有限兵力中选择支援重点。

预备队需要有明确数量限制、调动时间和路径，不能无限刷兵。

请让人类帝国表现得像一支真正有组织的防御军队，而不是大量独立运行的炮塔。

## 四、增加具有战术特色的新兵种

保留现有魔物和六大统帅，重点新增或改造以下两种兵种。

### 1. 哥布林掠夺者——经济型兵种

这是一种专门攻击资源设施的魔物。

特点：

- 移动速度较快。
- 战斗力较弱。
- 优先寻找敌方资源仓库、补给营地、魔晶矿和运输设施。
- 对资源建筑造成额外伤害。
- 摧毁资源目标后，为玩家获得额外魔晶。

要让玩家可以通过合理部署哥布林掠夺者，先夺取人类外围资源，再使用获得的资金购买更强的军队。

但不能让它们无视附近的严重威胁，盲目穿越整个城市去攻击远方资源。

允许玩家手动指定目标。

额外收益必须有一次性领取规则，不能通过重复攻击或刷新对象无限刷钱。

### 2. 流亡精灵法师——范围魔法兵种

设定为脱离人类帝国、与魔物王国结盟的流亡精灵。

特点：

- 远程魔法攻击。
- 对一定范围内多个敌人造成伤害。
- 适合清理密集步兵和弓箭手。
- 生命值较低，容易被骑士突击击败。
- 攻击存在合理的施法前摇和间隔。
- 受到墙体遮挡及射程限制。

可以设计火焰爆裂、冰霜爆炸等清晰的范围魔法效果，但首版只需要一种成熟可靠的主攻击机制。

不要让范围法师强到能够无脑摧毁整座城市。

### 兵种协同

请重新梳理不同兵种的战术价值。

例如：

- 岩甲巨人：破墙。
- 史莱姆：吸引火力、数量压制。
- 魔狼：高速突击。
- 蜥蜴射手：远程支援。
- 哥布林掠夺者：资源掠夺。
- 流亡精灵法师：范围清兵。
- 风暴飞龙：空中压制。
- 树人守卫：治疗与保护。

不要让所有兵种只是生命值、速度和攻击数字不同。

## 五、增加魔王主动法术系统

玩家作为转生的魔物之王，应该能够亲自干预战局。

保留原有统帅技能，新增一组通用魔王法术。

优先设计以下四种：

### 1. 狂暴术

选定一片己方区域。

短时间内提高魔物移动速度、攻击速度或输出能力。

适合在突破城门或集中总攻时使用。

### 2. 治疗术

选定一片己方区域。

逐渐恢复范围内魔物和统帅的生命值。

不能复活已经阵亡的单位。

### 3. 守护结界

在指定区域生成防护效果。

暂时降低友军受到的伤害。

适合保护岩甲巨人或正在通过危险街道的军队。

### 4. 陨星术

对指定区域发动一次范围魔法攻击。

适合清理密集守军或压制炮塔附近的敌人。

伤害需要合理限制，不能从地图外围直接一键摧毁中央圣晶。

### 魔法资源

建议采用简单的魔力值系统：

- 魔王拥有一个魔力槽。
- 魔力随战斗时间缓慢恢复。
- 不同法术消耗不同魔力。
- 强力技能需要较长冷却。
- 技能不能无限连续释放。

不要增加复杂的魔法研究、装备或成长系统。

### 技能交互

在下方原有出兵栏旁增加魔王法术栏。

玩家可以点击技能后在战场指定位置释放，也可以拖动技能图标到地图上释放。

必须有作用范围预览、释放反馈、冷却显示和魔力不足提示。

避免与六大统帅现有技能快捷键冲突。

## 六、重新调整战场经济

继续采用固定初始资金加战斗中获取资金的模式。

增加真正有价值的外围资源建筑，例如：

- 帝国魔晶仓库
- 军需补给站
- 魔晶矿场
- 帝国运输车

这些设施应分布在不同的战略位置。

攻击或占领它们可以获得魔晶，支持玩家继续购买军队。

尤其要让哥布林掠夺者发挥作用。

但不要把资源点全部放在一条路线，否则其他进攻方向会失去经济价值。

战斗中购买的新兵仍然进入库存。

玩家通过底部兵种栏将其部署到初始区域或已经合法占领的前线区域。

购买扣款与部署库存必须准确，不能重复扣费或凭空复制单位。

## 七、重新调整圣晶与胜负规则

唯一胜利条件仍然是：

**摧毁位于圣曜城中央核心的日轮圣晶。**

失败条件仍然是：

- 战斗倒计时归零。
- 全部兵力耗尽，且没有可购买、可部署或可召唤的有效作战力量。

不要恢复天数、长期养成、基地建设和多日经营。

不要再设计需要摧毁能源塔才能延长时间的机制。

日轮圣晶的充能只是倒计时的视觉表现。

### 核心平衡要求

当前存在核心目标过早被摧毁的问题。

请重点排查：

- 是否有超长攻击范围。
- 是否存在穿墙攻击或范围伤害穿透。
- 圣晶是否缺少合理的内城掩护。
- 是否有兵种过于容易绕过防线。
- 是否存在进攻方伤害或资源数值失衡。
- 是否有防御建筑和守军根本没有机会参与战斗。

不要通过直接将圣晶生命值提高10倍这种粗糙方式解决问题。

优先通过地图布局、空间距离、城墙、部署区域、交战射程、防御覆盖和敌方调兵改善。

请确保普通玩家在真正经过城池主要防御区域之后，才能稳定地攻击中央目标。

不强制清理所有建筑，避免把游戏做成机械的清单式闯关。

## 八、三档难度重新平衡

### 简单

允许玩家犯错，鼓励体验多个进攻方向。

但不应该开局无脑部署一批普通魔物就轻松击败中央核心。

### 普通

需要合理配兵、利用城墙缺口、资源掠夺、魔王法术和多路进攻才能提高胜率。

### 困难

人类拥有更合理的防御布局、更强的预备队和更高的战术压力。

但仍必须存在实际可行的获胜打法。

不要依靠无限刷敌军或者给全部建筑加巨额生命值制造困难。

地图扩大后，请根据实际测试重新校准三档难度的倒计时。不要机械沿用旧版时间，使军队还未抵达内城就因路程过长而失败。

## 九、重新强化城市美术和战争场面

我提供的截图反映出当前城市视觉上还有一个问题：一些建筑重复排列，整体更像战术沙盘，而不是真正的帝国城市。

请继续提升视觉质量。

特别是：

- 四个区域要有清晰的建筑层次与军事布局。
- 外围可以出现森林、道路、废墟、军营和资源设施。
- 外城应该拥有成片街区、城墙、城楼和市政建筑。
- 内城应该有宏伟的军事设施、骑士团驻地、魔法学院和圣殿建筑。
- 中央圣晶应具有非常突出的体积、光效和视觉地位。
- 不要大量重复同一栋建筑贴图，适当增加建筑类型、朝向、大小、装饰和街区变化。
- 城墙与建筑应有合理碰撞、遮挡和视觉层次。
- 数百只魔物进攻时，画面应像真实的史诗奇幻战争，而不是大量小图标移动。
- 新增哥布林掠夺者、流亡精灵法师的独立形象、动作和技能特效。
- 魔王的狂暴、治疗、守护、陨星等法术应具有鲜明而统一的视觉表现。

允许重新组织地图和重做不符合质量要求的资产。

但优先确保完整可玩和正常性能，不要为了装饰牺牲战斗可读性。

## 十、必须真实测试，不能只看编译结果

请先建立新旧版本的战斗对比测试。

特别验证：

1. 从东、西、南、北四个方向都能够发动真实有效的地面进攻。
2. 外围部队不会被不合理的内城建筑直接攻击。
3. 内城预备队能够沿道路真实增援外城。
4. 魔物破坏城墙后，寻路能够更新。
5. 哥布林掠夺者能够正确寻找、攻击资源设施并获得奖励。
6. 流亡精灵法师拥有真实的范围攻击，同时不会隔墙无限攻击。
7. 四种魔王法术有效，魔力、冷却和范围判定正确。
8. 玩家可以边打边购买，并从已占领区域部署援军。
9. 不同进攻路线具有实际的成本与收益差异。
10. 圣晶不能在没有合理突破防线的情况下被外围单位直接摧毁。
11. 简单、普通、困难模式都可以完成一局完整游戏。
12. 能够触发正确的胜利、超时失败和全军耗尽失败。
13. 数百只单位同时战斗时，游戏不会出现严重卡顿、卡墙、重复结算或失去响应。
14. 真实浏览器中城市全景、内城交战和核心决战的画面正常。

请尽可能使用自动化浏览器进行真实交互测试，并保存关键画面截图。

自动化脚本不应只通过直接调用内部胜利函数来验证通关，而应包含实际购买、部署、移动和战斗的端到端路径。

请至少设计并实测：

- 一种简单难度可获胜打法。
- 两种进攻方向或阵容不同的普通难度可获胜打法。
- 一种困难难度可获胜打法。
- 一种只用基础魔物无脑冲锋的失败案例。

如果实际测试不通过，先分析原因并修复，不要把未验证内容报告为完成。

## 十一、开发执行方式

我授权你在当前 SEAPP1 项目中进行必要的大规模重构。

可以删除已经确认废弃的旧系统和素材，但必须保留 Git 真实历史。

不要频繁询问我普通技术决策。

请连续推进：

M0：审查旧地图、战斗数值和当前问题。

M1：重建四层城市地图与四面进攻路线。

M2：改进人类防御、分区射程与预备队增援。

M3：新增哥布林掠夺者、流亡精灵法师和资源设施。

M4：实现魔王法术、底部技能栏与完整交互。

M5：三档难度重新平衡、性能优化与视觉精修。

M6：自动测试、浏览器验收、Bug修复、文档更新和正式部署。

允许根据技术依赖调整顺序，但应尽早完成可以实际游玩的战斗闭环。

每完成一个大阶段：

- 实现并验证对应功能。
- 自动修复发现的问题。
- 进行一次真实 Git commit。
- 有推送权限就 push 到 GitHub。
- 继续下一个阶段。

不要伪造历史，不要强推覆盖旧提交。

请保留原有课程开发记录，并更新 GDD、SRS、设计说明、测试报告和需求变更日志。

## 十二、最终交付标准

这次我最在意的不是又新增多少按钮，而是整个战争是否真正合理。

我希望最终体验是：
