# M0：纵深战役重制审查

基线：3527442（已发布游戏代码4256fab），2026-10-24。原V2课程文档与实测记录保留。

实际源码根因：

- simulation.ts 的攻击只比较距离，没有检查墙和建筑视线；近处范围攻击也不检查墙。射手可以隔墙射击，范围魔法/龙息也穿墙结算。
- world.ts 的城防几乎集中于南部，北部主要是渲染层民居；中央目标(1600,1000)也不在3200×2400地图的几何中心。后方没有对应战术区。
- 外墙横段与竖段连接处存在约26px间隙，原来单位采用点碰撞，可能绕过完整外墙。导航和攻击均缺少对这些漏洞的回归保护。
- canDeploy只承认南侧三块集结区；侧面、北面只是镜头可见，无法从对应方向开局。
- 守军仅统一360警戒约束；预备队按计时从南部军营产生三波，不能根据四个战区的压力分配已存在的有限部队。
- 已保存V2真实样本中，普通空袭36–40秒结束、困难空袭45.93秒结束，支持用户反馈。原数据见V2_BALANCE_RESULTS和V2_DIFFICULTY_RESULTS，不改写它们作为新版结果。
- 部署虽然已有1/3/全部，但一次成功后立即退出模式；大军每35ms逐个入场，300只需要10.5秒。重复点放、持续投兵与快捷集结都不顺手。

本轮方案：保持圣晶5600HP，通过4000×3600四面地图、外围/外城/内城/核心三重真实围墙、防区与视线、实体有限预备队、新资源经济、魔力法术改善节奏。四个方向允许独立突破，不要求清理建筑清单。

快速部署：1/3/5/10/全部批量；选卡后持续点放；按住地图连续向该坐标投入库存，松开/失焦/暂停立即停止；设定合法集结点后卡片旁一键投兵，Shift一键全部。队列每次最多4只、每40ms入场（仍受300上限），保留全部库存守恒。

验收结果将在实现后追加，当前文档仅记录源码审查与设计决策。
