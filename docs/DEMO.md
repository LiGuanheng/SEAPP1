# 课堂3–5分钟演示

1. 打开公开游戏，介绍“开局即最终总攻，中央圣晶是唯一目标”（20秒）。
2. 普通难度，进化专精；展示六位独立统帅立绘，选巨王/狼王/森灵，说明最多四位与招募费用（30秒）。
3. 军团整备加载“群山破城”，查看每批人数/价格、库存与剩余魔晶。说明战中可买兵、部署不再扣钱（30秒）。
4. 跳过巡城；用全景看中央圣晶、两层防线、三路入口与两个据点（15秒）。
5. 将巨王拖到西区，靠近薄弱墙后Q瞄准墙段；展示裂纹、碎石、实际缺口。将部分巨人/哥布林拖入，其他军队保留或全量排队（40秒）。
6. 框选、右键集火西重炮。狼类等主力接敌再用号令；受伤后使用女王治疗与魔王F进化祝福（30秒）。
7. 清除西前线守军并控制8秒，+200后点击买巨人/射手，从新前线拖出援军。需要时空格暂停说明（35秒）。
8. 用小地图/圣晶镜头展示内城决战；普通战报能原阵容重试。展示截图14的龙王技能，并说明另一套空袭策略与防空克制（30秒）。
9. 展示SRS→实现→测试的追溯表，真实阶段Git提交与浏览器/性能JSON（25秒）。

如现场不熟悉操作，可用简单难度熟悉后再展示普通难度策略报告。不要把测试快进、截图或预置配置说成独立人类实时通关；原始证据已经标注其方法。
