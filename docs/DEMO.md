# V3.1 课堂演示

1. 打开公开地址，展示三难度/三专精/六统帅，选普通群山破城。
2. 展示三环全景与四向资源；掠夺者分两队夺取外围物资，主力新部署保持原地。
3. 底栏切战场选兵，点卡片、框选、右键拖画路线、Shift追加和S停止，展示沿路优先资源/城防。
4. 用真实战利品购买巨人/精灵，破墙、拆炮、占西境前线，就地继续部署。
5. 展示相邻方向沿路援军、核心驻军与日轮守护骑士护盾/震荡，使用蛛后、治疗/守护等技能配合。
6. 明确集火圣晶获胜，等待结算再重试。困难直推/掠夺对比及真实截图、性能、失败样本在v3.1报告。

# V3 课堂演示建议

1. 打开在线游戏，展示难度预算与三专精、六统帅、新增掠夺者/精灵。
2. 简单/进化/群山破城预设进入战场，先全景说明四层城池与四面集结。
3. 点西境，展示1/3/5/10/全部；选卡反复点放，再长按同一个位置，松开停止。设置集结点，演示卡片一键出兵和Shift全部。
4. 掠夺者收割附近资源，讲解一次性奖励与战中购买；巨王Q指定可见墙段，观测缺口和实际通行。
5. 前线占领后设置该处为集结点，真实扣款购兵并一键投放援军。
6. 用Z/X/C/V演示法力、冷却和范围预览；用治疗/守护保护精锐，展示精灵范围焰爆和内城预备队实际移动。
7. 框选、右键移动、集火、编队；推进内城/核心并摧毁唯一目标，不必全清建筑。结算原阵容重试。
8. 展示实际测试报告、基础魔物力竭和超时截图，以及真实阶段Git历史/构建源SHA。长战役脚本采用模型快进，要如实说明。
