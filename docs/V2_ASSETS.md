# V2 原创资源登记

所有 V2 图片均于本次开发会话通过内置 imagegen 生成并实际整合；未下载或挪用商业游戏素材。人物、世界观与标识均为本项目原创设计。原始输出保留，生成提示的要点如下。

| 文件 | 用途 / 生成说明 |
|---|---|
| cover | 白金帝国圣曜城、风暴龙与岩铠巨王的史诗封面 |
| portraits | 六位原创统帅的统一成熟奇幻肖像图集 |
| units / units-move | 十种魔物、帝国守军与魔王，俯视战斗图集和替代动作帧 |
| structures | 六种真实可破坏或可攻击的帝国军事设施 / 圣晶 |
| city | 圣殿、民居、图书馆、商会、堡楼、军马厩、庭园与门楼 |
| materials | 石路、草地、墙石、蓝瓦材质 |
| grove | 原创树木与岩石组合，替换早期几何树冠 |
| hero-dragon / hero-titan / hero-moon / hero-web / hero-forest / hero-emperor | 六位统帅各自独立的完整战斗精灵，避免共享图集串图 |
| heroes | 早期统帅图集，已由独立素材替代，保留为开发来源 |

图片负责造型，移动、攻击、受击、死亡、翅膀振动、石墙裂纹、碎石、弹道、法阵与技能范围由实时渲染和真实事件驱动。不是用静态封面替代战斗。

音效全部由 Web Audio 程序合成，无外部音频。字体优先系统中文衬线与无衬线字体，无外部字体加载依赖。

第三方代码依赖以 package-lock.json 为精确版本依据：TypeScript / Puppeteer 为 Apache-2.0，Vite / Vitest / Prettier 为 MIT。V1 素材与许可另见历史文档，不进入 V2 正式运行路径。
