## 1. 软件目标与范围

### 1.1 目标

一款**无需后端、可在桌面浏览器直接游玩**的 2D 暗黑奇幻攻城策略游戏。玩家扮演原创亡灵君主，在固定大地图上经营亡灵腹地、按日繁殖尸群、改造精锐、夺取前线，逐日进攻会同步发展的人类最后之城「曙光城」。灯塔持续充能，玩家必须在净化完成前摧毁灯塔，或在最后关头发动一次性终局「万骸归一」，把全部资产转化为最终大军。

核心体验：**规模成长（60 → 数百）**、**真实突破（墙体与设施跨天受损）**、**战略决定终局（断能源 / 破门斩首 / 尸海速攻）**。

### 1.2 范围内

- 单人战役，固定地图，回合制经营 + 实时攻城混合。
- 亡灵经济（尸骸 / 变异精华）、建筑建造升级、兵种改造、Boss 解锁。
- 实时战斗：批量部署、自动索敌、集火/集结命令、可破坏墙体与建筑、塔防反击。
- 人类 AI：预算约束下的补兵、修墙、建塔、反攻。
- 灯塔倒计时、多日战役、跨日持久化、本地存档。
- 终局献祭、君主化身、全军冲锋、胜/负结局。
- GitHub Actions CI、GitHub Pages 部署。

### 1.3 范围外（V1 不做，明确记录）

- 独立白天探索地图、角色步行探索。
- 多人联机、后端账号、付费服务、数据库。
- 3D、移动端触屏适配（仅保证桌面 1366×768 以上）。
- 六兵种 / 四 Boss 全量、完整 6 建筑科技树、全自由破坏、450–500 单位高精度 AI。
- 复杂剧情树、配音、CG 视频。

### 1.4 参与者

| 参与者 | 说明 |
|---|---|
| 玩家 | 亡灵君主，唯一人类操作者 |
| 人类城防 AI | 规则驱动的对手，受预算/槽位/建筑存活状态约束 |
| 课程验收者 | 克隆仓库、安装、运行、测试、查看提交历史与线上地址 |

### 1.5 运行环境

- Chrome / Edge 最新两个大版本，桌面分辨率 ≥ 1366×768，WebGL 可用。
- 构建产物为纯静态文件，可托管于 GitHub Pages 子路径 `/SEAPP1/`。
- 无网络亦可游玩（除首次加载静态资源）。

## 5. 关键业务规则与边界

1. **第 1 天不结算繁殖**：开局直接使用 60 食尸鬼库存，避免「初始 60 + 当日 +12」重复记账。
2. **建设次日生效**：当日投入资源的建造/升级只在下一个战役日的生产阶段生效，当次攻城不享受收益。
3. **能源站当日生效**：战斗中被摧毁的能源站在**当日战后**的充能结算中立即不计入。
4. **墙体永久缺口**：完全摧毁的墙段跨日保持 `destroyed`，不能被修复；受损未毁可花费预算修复。
5. **前线延迟解锁**：占领当日的战斗内不开放新部署区；次日检查连通后才激活。
6. **不重复转化**：人类士兵死亡只产生一次转化判定（20%，单场上限 15），同一尸体不可重复领取。
7. **统御 vs 库存**：库存是长期资产；统御是单场可部署上限（王座 I/II/III = 180/300/450）。终局解除统御限制但保留活动单位上限。
8. **终局一次**：`finalAssaultTriggered` 只能 false→true 一次；终局后无生产、无下一天、无维修。
9. **结算顺序**：攻城胜利判定优先于日终充能判定（同一天先打爆灯塔则胜利）。
10. **暂停/倍速**：暂停时模拟时间停止；倍速只改变模拟步进频率，不重复执行日结算。
