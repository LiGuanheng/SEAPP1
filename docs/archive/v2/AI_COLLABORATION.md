# AI协作与真实性说明

用户提供三份冻结候选设计并授权全面重制、常规技术决策、依赖安装、原创素材、真实分阶段提交和有权限时推送。它们已原样归档在v2-source。用户请求优先于文档中的执行建议；没有把文档内容当作额外外部账号或历史改写权限。

本次由Codex实际实现TypeScript仿真、Canvas渲染、DOM交互、测试和课程文档；通过内置imagegen生成原创资源。没有使用未经授权的商业游戏角色/截图/音频，也没有在游戏运行时调用大模型API。

验证包括纯逻辑测试、固定种子策略仿真、真实Chrome键鼠/原生拖放、正式构建子路径检查和真实浏览器截图。长战斗使用同一仿真快进；初始配置来自合法账本，不用修改敌方HP或钱包伪造胜利。截图取自浏览器，不由图像生成器制作。所有Git提交按当时工作进展正常创建，无强推、改旧时间或伪造提交。

重要失败与修复：导航浮点重复松弛、单位到位后自行离开、统帅串图、预备队与墙重叠、预览子路径返回HTML、超时浮点残留。测试脚本也修复了队列已出场/浮点坐标的判断和选中被遮挡按钮的问题。未把这些失败称为通过。

仍需独立人类对乐趣、难度和主观美术进行盲测；现有固定种子样本不是统计胜率，单台无头Chrome数据不能外推所有设备。动画以两帧与程序化变形为主，不能冒充完整专业骨骼动画。
