# V2 关键决策索引

详细过程见 `V2_DECISIONS.md`、`V2_CHANGELOG.md`；V1设计另存archive/v1。

| 决策 | 原因 / 后果 |
|---|---|
| 彻底退出经营与尸巢主线 | 单场最后总攻与课堂演示优先，避免旧状态残留 |
| Canvas 2D + 独立模型 | 允许Node直接验证规则，不把UI/美术生命周期与模拟绑死 |
| 固定60Hz与确定性随机 | 不同显示刷新率不应改变同一输入序列结果 |
| 主动技能由玩家指定 | 保留局部战况的关键决策，普通攻击仍自动 |
| 高代价流场 + 真实墙碰撞 | 能规划攻城目标，同时必须真拆墙后通行 |
| 队列与库存分离 | 活动300限制不吞兵、不重复收费，可累计1000+出征 |
| 移动命令到位驻留 | 避免被自动进攻覆盖；全军冲锋提供明确恢复手段 |
| 原创图集 + 独立英雄 | 统一风格并修复大体型图集边缘串图 |
| 原PNG保留、发布WebP | 保留资产来源与重新编码能力，降低公开网页加载体积 |
| controlled main阶段正常提交 | 用户明确授权；旧历史完整可回退，无强推 |
| 文档专属提交不重复部署 | CI忽略docs/art-source/README，运行代码或发布资源改变时才重建；可手动dispatch |
